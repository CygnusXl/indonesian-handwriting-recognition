# Results

This directory contains generated figures, tables, experiment histories, and experiment summaries.

All metrics below come from actual project runs.

## Metric standardization

For the final report, the **primary overall metrics** will be:

- **Corpus CER:** total character edit distance divided by total reference characters.
- **Corpus WER:** total word edit distance divided by total reference words.
- **Exact match:** proportion of samples whose complete prediction exactly matches the reference.

**Macro-CER** (mean of per-sample CER values) remains a secondary diagnostic metric for subgroup/error analysis because it weights each sample equally.

The earlier comparison mixed aggregation conventions. The standardized comparison (`src/compare_experiments.py`, now superseded by `src/analyze_model.py --model all` + `src/report_assets.py`) recomputes every model on the same 208 test samples with corpus-level CER/WER.

## Line-level view with confidence intervals

`python src/line_level_report.py` re-aggregates the saved per-sample predictions (no model is run) into single-line vs multiline tables with bootstrap 95% intervals and paired gaps to the baseline. Output: `results/analysis/line_level_report.md` and `.csv`. Baseline: single-line corpus CER 17.1% (14.4–20.0% by writer bootstrap) vs multiline 90.3% (88.9–91.5%); multiline samples hold 70.6% of the reference characters. The effect of the page pipeline's line splitting on the multiline samples is **not** measured here (needs the dataset images). Intervals cover test-set sampling noise only; there is one training run per model.
