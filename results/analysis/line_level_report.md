## 3. What this does and does not show

**Observation.** For every model the single-line and multiline rows differ by a wide margin, far wider than the intervals above. The pooled CER is therefore a mixture of two regimes, not one typical error rate.

**Not measured here.** The effect of the page pipeline's line splitting on the multiline samples. That needs the dataset images, which are not in the repository; the splitting has only been checked on five dataset sample crops (see `DOCUMENT_PIPELINE.md`). To measure it, run `python src/evaluate_pipeline.py` on the multiline test images with ground truth (see `evaluation/real_world/README.md` for the input layout).

**Limits.** One training run per model: the intervals cover test-set sampling noise only, not training-seed variance, so they understate the real uncertainty. The test set has 130 writers with at most 4 samples each, which is why resampling by writer changes the intervals very little. Samples from the same writer are correlated, so quote the writer interval.
