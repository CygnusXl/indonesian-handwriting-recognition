# Data

This directory contains dataset documentation and local dataset storage.

## Policy

Raw and processed datasets should not be committed to Git unless their license, size, and project requirements explicitly permit it.

Record the following for every dataset used:

- Source and URL
- License
- Language
- Number of samples
- Writer information
- Labels / transcription format
- Train/validation/test split
- Image characteristics
- Known quality issues
- Known limitations and bias
- Preprocessing steps

The actual dataset will be selected only after verification against the project requirements.
